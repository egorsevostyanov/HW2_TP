Название проекта: система для управления рецептами.
Описание: Это консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", масштабировать порции и генерировать список покупок.

Как использовать:
Можно создавать ингредиенты через класс Ingredient. Из ингредиентов можно создавать рецепты (Recipe) и рецепты с диетической категорией (DietaryRecipe), а из рецептов можно создавать список покупок (ShoppingList). Списки покупок можно объединять между собой, добавлять рецепты, удалять рецепты (точнее ингредиенты из этих рецептов).
Для использования этих классов надо импортировать классы в новый python файл, и использовать их там (from hw2 import ...), либо писать код в самом hw2.py
Для запуска тестов надо в терминале написать команду pytest test_recipes.py -v (-v для указания названий тестов)
